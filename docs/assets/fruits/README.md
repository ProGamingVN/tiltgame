# Ảnh pixel art cho game Chém Hoa Quả 3D

Bỏ các file PNG (nền trong suốt) vào đúng thư mục này với đúng tên như dưới đây.
Game đọc ảnh theo đường dẫn tương đối `assets/fruits/<tên>.png` tính từ file
`fruit_ninja_3d.html`.

## Danh sách file cần có

| Tên file cần đặt | Dùng cho |
|---|---|
| `apple.png` | Táo |
| `orange.png` | Cam |
| `watermelon.png` | Dưa hấu |
| `kiwi.png` | Kiwi |
| `grape.png` | Nho |
| `bomb.png` | Bom |

**Yêu cầu ảnh:**
- Định dạng **PNG, nền trong suốt** (không nền trắng/đen).
- Ảnh vuông, kiểu pixel art, khoảng **32×32 đến 128×128px** là đẹp (game tự scale, không cần chỉnh).
- Bomb nên có màu tối/đen rõ để nổi bật trên nền sáng.

> Chưa kịp tải ảnh? Không sao — game tự vẽ hình khối màu thay thế tạm để chạy được ngay,
> bạn thả ảnh thật vào thư mục này bất cứ lúc nào, load lại trang là thấy ảnh thật.

## Vài chỗ tải ảnh pixel art miễn phí (kiểm tra license trước khi dùng)

- **itch.io** — kho asset lớn nhất, lọc theo "free":
  - https://itch.io/game-assets/free/tag-fruit/tag-pixel-art (nhiều pack trái cây pixel, miễn phí)
  - https://itch.io/game-assets/free/tag-cc0/tag-pixel-art (CC0 = dùng thoải mái, không cần ghi credit)
  - Gợi ý cụ thể từng thấy: *"Free Pixel Art Fruits"* của ThiagoZen (apple, orange, watermelon, grape, kiwi — 32×32, giấy phép CC-BY 4.0, phải ghi credit tác giả), *"Pixel Fruits & Vegetables Pack"* của Rcp Studios (32×32, nhiều loại quả kể cả bản có viền đen/không viền).
- **OpenGameArt.org** — tìm từ khóa "fruit pixel" hoặc "bomb pixel", nhiều asset CC0/CC-BY.
- **Kenney.nl/assets** — tất cả đều **CC0** (không cần credit), tìm "bomb" hoặc "icon" rất hợp để lấy ảnh bomb.

Lưu ý: gói nào ghi **CC-BY** thì bắt buộc ghi tên tác giả ở đâu đó (ví dụ trong README repo của bạn),
gói ghi **CC0** thì dùng tự do không cần credit. Đọc kỹ trang tải trước khi dùng cho mục đích thương mại.
