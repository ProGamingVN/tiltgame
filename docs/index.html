Cách chơi: nhấn Kết nối ESP32, chọn cổng của board (đang chạy firmware esp32_mpu6050_firmware.ino gửi dữ liệu roll,pitch). Nghiêng module để di chuyển lưỡi dao, nghiêng nhanh qua trái cây để chém. Chạm bom màu đen là thua ngay. Để quả rơi mất không chém trúng sẽ mất 1 mạng. Bấm ⛶ Toàn màn hình để chơi rõ hơn. Chỉ chạy trên Chrome/Edge desktop. Chưa có board? Dùng chuột/ngón tay rê trên khung chơi để chém thử.

Ảnh trái cây/bomb: đặt file PNG nền trong suốt vào thư mục assets/fruits/ (xem assets/fruits/README.md để biết tên file cần và chỗ tải ảnh miễn phí). Chưa có ảnh thì game tự dùng hình khối màu thay thế, vẫn chơi bình thường.
